Web dev

Portfolio revamp 2026

The original revamp of this site was meant to reduce load time, so there was only one page that opened up a bunch of models. I created a model of this on codepen to see if this idea would work. Here's a link to take a closer look at the codepen experiment: check out this codepen

Over time, I realized the code wouldn't be that scalable though, so another complete refactor was needed. This would also be an opportunity to experiment more with what simple markup could do. I learned a lot about web components and how they could make markup more convenient and avoid repeats thanks to this project. Plus it contextualizes how frameworks like ReactJS or VueJS came to be.

Art Portfolio 2024

This project was for an art focused portfolio where I could experiment with react hooks and web design more. I'vew seen plenty of artists play with making their sites look handmade, and that amused me. So I thought I would try my own version of it in ReactJS.

This project was also an opportunity to play with dynamically generated content alongside the frontend framework react. Of course I'm always trying to review how react hooks work too. From a design perspective though, it's not the most suited to a recruiter's tastes.

Writing Site

Another portfolio site made from React JS where I get to review hooks more. Plus It's an opportunity to play with react packages I was unfamiliar with like the page-flip package that allows for magazine page flip effects online.

App dev

Electron

These experiments were for the purpose of teaching myself the electron framework. I was inspired by nashallery (a product designer and developer my sister follows) and my sister herself. Their early projects were basic egg timers. To differentiate, I made a timer tailored to different baked goods.

The second electron project was a basic organizational app that I made to solve a problem I had. Youtube doesn't allow you to organize subscriptions by genre, so I thought it'd be cool to have a personal one for myself. This project allowed me to learn about different aspects of the electron framework.

Streamlit

The streamlit library was new to me, but I had learned enough python to understand the basics. Plus it helped a lot that that syntax was pretty self explanatory. The first streamlit app I started with was a simple QR code maker. I had needed one for an in person market I was doing and most of the ones online require logins or a payment. There was a python tutorial on codedex that showed you how to make a qr code maker with customizabale background and qr code colour, so I thought of adding onto that by translating that code to streamlit.

Another app I made was a mini zine maker. This one was more difficult for me because I was rusty with image manipulation in python.

This third app was to solve another personal problem I had, but also learn about streamlit's data interpolation features. This app is meant to categorize a dvd collection into a searchable and organized database. It allows the user to display different data points like genre and year (among other things).
